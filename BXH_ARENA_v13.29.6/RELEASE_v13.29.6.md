# BXH ARENA v13.29.6 修復版

本次以 v13.29.5 為基底，整合現場賽事發布及簽到頁修正。

## 更新內容

- 賽事設定底部新增「完成架構並發布／更新並重新發布」入口，現場報名也可發布。
- 現場報名發布只檢查賽事名稱、日期與地點；線上報名仍檢查報名時間與名額。
- 現場報名發布預覽不再顯示不適用的線上報名時間、名額與取消期限。
- 尚未取得雲端房間代碼時顯示「草稿已儲存，尚未發布」，分享中心提供發布指引。
- 每日簽到狀態文字不拆行；說明文字移至標題下方。極窄畫面可將整個狀態標籤換列。
- 每日簽到頁上方新增「返回賽事大廳」；讀取中、未開放或連線錯誤時仍可返回。
- 返回大廳時回到頁面頂端。
- 保留 .5 的裁判跳過、承接、指派及同步保護。

## 如何更新

1. 備份網站目前的 index.html。
2. 使用本包 index.html 覆蓋 GitHub Pages 原檔案並發布。
3. 網站更新後重新整理，確認顯示 v13.29.6。裁判裝置請統一重新整理。
4. 開啟既有現場報名賽事，確認「完成架構並發布」可開啟預覽；確認發布後應取得房間代碼及分享入口。
5. 手機查看每日簽到，確認狀態文字與返回鍵。

只需更新前端。Functions 程式仍為 13.29.4，Rules 仍為 .4；無須重新部署 Firebase、重建賽事或清除資料。
包內 functions/ 與 Rules 為完整備份，Node 設定沿用 22。
